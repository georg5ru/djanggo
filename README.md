# Интернет-магазин

Этот проект — интернет-магазин, созданный на Django в рамках курса.

## Функционал

- Главная страница (`/`)
- Страница контактов (`/contacts/`)

## Технологии

- Python
- Django
- HTML
- Bootstrap

## Установка

1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите сервер: `python manage.py runserver`
